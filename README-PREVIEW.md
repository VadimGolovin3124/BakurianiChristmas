# MTA · Bakuriani — Winter Redesign

Локальная демонстрация сезона 2026/2027 на основе присланного макета Stitch.

## Просмотр

Обычная страница: http://127.0.0.1:5182/

Кабинет хозяйки: http://127.0.0.1:5182/host

Для повторного запуска из этой папки:

```
node node_modules/vite/bin/vite.js preview --host 127.0.0.1 --port 5182
```

Пересборка: `node node_modules/typescript/bin/tsc --noEmit` и `node node_modules/vite/bin/vite.js build --mode beta`.

## Границы демонстрации

- Фото, галерея, 3D-модель, тексты на трёх языках и интерфейсы бронирования взяты из проекта квартиры.
- Цена, вместимость, заявки, закрытые даты и зимняя тема хранятся локально в браузере.
- Авторизация, Telegram, WhatsApp и ответы помощника демонстрационные. Запросы не отправляются на боевые серверы.
- В этой папке нет конфигурации для деплоя и ключей. Она не предназначена для публикации.
- Если дизайн будет одобрен, его следует перенести в основной проект, сохранив настоящие серверные интеграции и авторизацию.
